Deploy a Bun HTTP server to Prisma Compute. Bun.serve apps are supported directly, no bundler or adapter required.

## Prerequisites

- [Bun](https://bun.sh) installed locally
- A Prisma account

## 1. Initialize the app

```bash
mkdir my-app
cd my-app
bun init --yes
```

## 2. Replace `index.ts`

```typescript title="index.ts"
Bun.serve({
  port: Number(process.env.PORT ?? 3000),
  fetch() {
    return new Response("Hello from Compute");
  },
});
```

Reading `PORT` from the environment keeps the server aligned with Compute's injected port.

## 3. Authenticate and deploy

```bash
prisma auth login
prisma app deploy --app my-app --http-port 3000
```

The first deploy bootstraps project context. Re-deploys reuse the saved selection, so `prisma app deploy` is enough.

In CI, set `PRISMA_API_TOKEN` instead of running `prisma auth login`.

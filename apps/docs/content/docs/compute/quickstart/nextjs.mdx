Deploy a Next.js app to Prisma Compute. This quickstart covers scaffolding a fresh app, enabling the standalone build output Compute requires, and running the first deploy.

## Prerequisites

- Node.js 20 or later
- A Prisma account


## With create-prisma

Use `create-prisma` to scaffold a Next.js project with all the dependencies needed.

```npm
npm create prisma@latest -- --template next
```

## Manually

### 1. Scaffold the app

```bash
npm create next-app@latest my-app --yes
cd my-app
```

### 2. Enable standalone output

Edit `next.config.ts`:

```typescript title="next.config.ts"
const nextConfig = { output: "standalone" };
export default nextConfig;
```

Compute deploys Next.js apps from the standalone build. Without this flag, the build output does not include the server entry Compute expects.

### 3. Authenticate and deploy

```bash
prisma auth login
prisma app deploy --app my-app --http-port 3000
```

The first deploy bootstraps project context. Re-deploys reuse the saved selection, so `prisma app deploy` is enough.

In CI, set `PRISMA_API_TOKEN` instead of running `prisma auth login`.

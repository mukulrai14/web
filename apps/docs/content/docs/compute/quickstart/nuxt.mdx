Deploy a Nuxt app to Prisma Compute. Nuxt builds with the Nitro `node-server` preset by default, so no adapter config is required.

## Prerequisites

- Node.js 20 or later
- A Prisma account


## With create-prisma

Use `create-prisma` to scaffold a Nuxt project with all the dependencies needed.

```npm
npm create prisma@latest -- --template nuxt
```

## Manually

### 1. Scaffold the app

```bash
pnpm create nuxt my-app
cd my-app
```

No extra config is needed. The default build output targets Node.

### 2. Authenticate and deploy

```bash
prisma auth login
prisma app deploy --app my-app --http-port 3000
```

The first deploy bootstraps project context. Re-deploys reuse the saved selection, so `prisma app deploy` is enough.

In CI, set `PRISMA_API_TOKEN` instead of running `prisma auth login`.

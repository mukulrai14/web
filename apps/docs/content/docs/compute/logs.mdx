Stream runtime logs for your deployment.

## Stream logs

```bash
prisma app logs
prisma app logs --deployment <deployment-id>
prisma app logs --tail 200
```

## Limits

- Stream caps at around 10 minutes. Reconnect to resume.
- One concurrent log stream per deployment.

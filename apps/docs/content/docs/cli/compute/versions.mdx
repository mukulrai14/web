The `prisma compute versions` command group manages deployed versions on Prisma Compute.

Use it to inspect, promote, start, stop, or delete versions after a deploy.

## Usage

```bash
prisma compute versions [command] [options]
```

## Subcommands

| Command                    | Description                                                         |
| -------------------------- | ------------------------------------------------------------------- |
| `prisma compute versions list`    | List versions for a compute service                           |
| `prisma compute versions show`    | Show version details                                          |
| `prisma compute versions start`   | Start a version                                               |
| `prisma compute versions stop`    | Stop a version                                                |
| `prisma compute versions delete`  | Delete a version                                              |
| `prisma compute versions destroy` | Stop and delete a compute version                             |
| `prisma compute versions promote` | Promote a version to the service endpoint and start it if needed |

Use `prisma compute versions <command> --help` for more information about a specific command.

## Common workflows

- Use `list` to find the versions available for a service.
- Use `show` to inspect a specific version before taking action.
- Use `start` and `stop` to control runtime state.
- Use `promote` to point the service endpoint at a specific version.
- Use `delete` or `destroy` when cleaning up versions you no longer need.

## Examples

### Show the available version commands

```npm
npx prisma compute versions --help
```

### Get help for a specific subcommand

```npm
npx prisma compute versions promote --help
```

### Typical post-deploy flow

```npm
npx prisma compute versions list
npx prisma compute versions show <version-id>
npx prisma compute versions promote <version-id>
npx prisma compute logs <version-id>
```

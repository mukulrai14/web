The `prisma compute logout` command clears stored Prisma credentials from your local environment.

## Usage

```bash
prisma compute logout [options]
```

## Options

| Option         | Description          |
| -------------- | -------------------- |
| `-h`, `--help` | Display help message |

## Examples

```npm
npx prisma compute logout
```

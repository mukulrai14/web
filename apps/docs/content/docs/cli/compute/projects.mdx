The `prisma compute projects` command group manages Prisma Compute projects.

Use it to inspect and work with the projects available in your Prisma account.

## Usage

```bash
prisma compute projects [command] [options]
```

## Subcommands

| Command | Description |
| ------- | ----------- |
| `prisma compute projects list` | List projects in your workspace |
| `prisma compute projects create` | Create a new project |

Use `prisma compute projects <command> --help` for more information about a specific command.

## Common workflows

- Use `list` to inspect the projects available in your workspace.
- Use `create` before provisioning services in a brand new project.
- After choosing a project, continue with `services` and `deploy`.

## Examples

### Show the available project commands

```npm
npx prisma compute projects --help
```

### Get help for a specific subcommand

```npm
npx prisma compute projects create --help
```

### List projects in your workspace

```npm
npx prisma compute projects list
```

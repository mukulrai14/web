The `prisma compute services` command group manages Compute services inside a Prisma project.

Use it to inspect the services associated with your applications and deployments.

## Usage

```bash
prisma compute services [command] [options]
```

## Subcommands

| Command | Description |
| ------- | ----------- |
| `prisma compute services list` | List compute services |
| `prisma compute services create` | Create a compute service |
| `prisma compute services show` | Show compute service details |
| `prisma compute services delete` | Delete a compute service |
| `prisma compute services destroy` | Destroy a service: stop and delete all versions, then delete the service |

Use `prisma compute services <command> --help` for more information about a specific command.

## Common workflows

- Use `list` to see the services available in a project.
- Use `show` to inspect a specific service before deploying or cleaning it up.
- Use `create` when you want to provision a new service before deploying into it.
- Use `delete` or `destroy` when removing services you no longer need. `destroy` performs a full cleanup first.

## Examples

### Show the available service commands

```npm
npx prisma compute services --help
```

### Get help for a specific subcommand

```npm
npx prisma compute services destroy --help
```

### List compute services

```npm
npx prisma compute services list
```
